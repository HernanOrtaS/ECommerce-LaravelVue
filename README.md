
# Ecommerce (Laravel Vue)

This project is created using Laravel and Vue frameworks, in docker containers. The objective it's create an admin dashboard to manage the process, data and products showed in the frontend.
I'm going to still learning about Vue because I'm interesed of the way of create resources.

I've added an autoinstall for linux users


## Run Locally

Clone the project

```bash
  git clone https://github.com/HernanOrtaS/ECommerce-LaravelVue.git
```

Go to the project directory

```bash
  cd LaravelApiVueStore
```

Run the autoinstall

```bash
  bash ./autoinstall.sh
```

Open your browser in

```bash
  http://127.0.0.1:8000/
```

Login with admin credentials

```bash
  admin@email.com
  12345
```
